# Các bản thử giao diện

Những file HTML trong thư mục này là các phương án giao diện đã được thử trong quá trình phát triển. Chúng được giữ để tham khảo và tiếp tục chỉnh thiết kế, không được sao chép vào build ứng dụng.

Giao diện đang sử dụng nằm ở `frontend/src/features` và `frontend/src/app`. Tài nguyên PWA nằm ở `frontend/public`.
